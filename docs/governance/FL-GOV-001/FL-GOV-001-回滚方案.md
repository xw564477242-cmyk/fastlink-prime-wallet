# FL-GOV-001 回滚方案

本次只新增治理文档与证据，没有运行态、数据库、秘密或环境变更。

尚未合并时：保留原工作区及证据包；如决定撤回 PR，由获授权人员关闭 PR，分支与提交保留。无需运行任何部署回滚命令，不自动删除分支。

若未来经评审合并后决定撤销：另行获批后，在新的功能分支上 revert 本工单治理提交，通过仅指向 dev 的 PR 评审撤销。逐项核对 diff 仅删除/撤销本目录新增文件；禁止 reset --hard、强推、amend 或改写已发布历史。若目录后来被其他工单更新，先评估冲突，不能整体覆盖。

原本地用户改动未写入本工单，因此回滚本工单不会撤销这些改动。不得用恢复本工单名义清理 outputs、修复失效工作树、重置长期分支或处置历史秘密。
