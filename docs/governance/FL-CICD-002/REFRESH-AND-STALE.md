手动刷新流程：
1. 独立工单明确准确URL/来源、请求权限、使用与分发权、版本及期限；项目所有者批准后才获取。
2. 原输入保留；在新700目录/600文件接收，记录实际时间或未知、字节数和SHA。
3. 对新旧结构做脱敏差异、兼容及负例测试，不复制候选正文进Git。
4. 总控审核固定输入范围、版本适用性、Secret更新权限和回滚指纹。未经专项授权不得更新、删除或轮换现有Secret。
5. 经五级门禁提交新pin与治理差量；核对Secret存在性和CI，不自动覆盖旧证据。
6. 如撤销批准，暂停相关输入链；不得以在线回退、跳过或旧宽校验维持绿灯。
