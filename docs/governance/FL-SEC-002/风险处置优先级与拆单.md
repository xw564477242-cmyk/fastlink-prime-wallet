# 风险处置优先级与拆单

P0审核队列为88项High，建议24小时内责任角色认领及离线初审。优先核实生产、高权限、资金/数据库、跨仓传播影响；当前未知项不能编造排序依据。2917项用途审核按配置与第一方调用关系优先，其余历史/依赖/制品需来源说明；建议2个工作日认领、5个工作日反馈。

每项High均列独立P0工单触发条件：所有者确认生产或高权限影响时立即拆单；当前不把全部88项直接认定为有效凭据或已批准轮换。

建议拆单类型：凭据吊销/替换与依赖更新；业务代码秘密移除；历史或归档治理；处置后复验。实施须逐单确认范围、责任人、依赖、回滚及门禁，不携带秘密原文。

建议顺序：离线确认归属/环境/权限→评审处置及连续性方案→独立授权下由所有者执行→代码/历史治理另审→核对秘密管理版本、授权审计和部署证据，重新本地扫描。复验不使用发现的凭据登录。

本工单不执行任何吊销、轮换、生产修改、源码清理或历史操作。
