# 密钥、证据及临时资产生命周期建议

|对象|当前建议|决策角色|后续获批条件|
|---|---|---|---|
|HMAC密钥|继续600、父目录700受限保留；禁止输出、删除|FastLink安全负责人|确认旧新指纹复核期、备份责任及销毁审计方案后另行批准|
|旧版/新版脱敏证据|并存、记录SHA及版本，不覆盖|FastLink安全负责人、控制与归档资产负责人|审计保留期和恢复验证通过后再决定归档|
|14个恢复目录|保留700，不转为正式工作区；临时目录无长期保证|控制与归档资产负责人|另单建立受控长期存储与恢复验证，禁止本单迁移或删除|
|隔离扫描目录|继续受限保留，不扩散源码|FastLink安全负责人|确认复核需要、最小访问和后续清理审批|
|交付证据包|保留脱敏版、SHA清单与门禁记录|控制与归档资产负责人|确认保留周期及访问主体|

权限700不隔离同UID或管理员。建议安全负责人交接后2个工作日指定保全责任人、5个工作日提出长期存储方案；这些是待确认建议，不是销毁授权。
