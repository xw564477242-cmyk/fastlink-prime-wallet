## 前端最小启动方式

推荐入口（不自动打开浏览器；Ctrl-C停止）：`python3 /Users/ck/Developer/FastLink/.tooling/start-local.py <仓库名>`，支持新钱包、旧App、Admin、Website四仓。入口版本见templates/start-local.py及校验清单，Website拒绝点文件、目录列表及越界链接。

也可进入对应正式仓库，在清理过的环境中调用：

```text
env -i PATH=/opt/homebrew/bin:/usr/bin:/bin TMPDIR=/Users/ck/Developer/FastLink/.tooling/tmp VITE_FASTLINK_API_URL=http://127.0.0.1:46199 VITE_FASTLINK_ENVIRONMENT=SANDBOX /usr/bin/sandbox-exec -f /Users/ck/Developer/FastLink/.tooling/profiles/local-only.sb /opt/homebrew/bin/node node_modules/vite/bin/vite.js --host 127.0.0.1 --port <该仓端口> --strictPort --mode development
```

健康检查只读取本机首页HTTP状态，验证后停止服务。Website无需依赖安装或构建，采用只读、拒绝点文件访问的回环静态HTTP服务验证首页。控制库为命令行治理包，不伪造Web健康端点，使用只读validate；默认test包含写入控制循环，因此不执行。
