# 现场保护方法

本轮开始及结束对原项目常规文件逐文件计算SHA-256，比较文件集合、内容、权限、UID/GID；目录元数据、符号链接目标文本的既有域分离HMAC及五个Git工作区状态分别比较。Git读取禁用可选锁，不执行fetch、prune或GC。

机器全量清单留在本机受限证据目录，不上传原始路径或内容；前后清单SHA-256及变化计数见source-protection-before.json和source-protection.json。清单包含采集上下文，前后清单总SHA不同不能直接等同于资产变化，应查看逐项比较结果。14个恢复目录仅核对HEAD、工作区及700权限；HMAC密钥只核对保留状态与600/700权限，不记录密钥材料。

此次比较只覆盖FL-DEV-001本轮区间，不能补证历史580个文件型链接的首次目标证据缺口。
