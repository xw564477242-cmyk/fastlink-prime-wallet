# 任务工具修订及边界

Session在容器内部合并输出流；错误行与当前结束帧SQLSTATE必须一致，冲突标记DESYNCHRONIZED并失败关闭。保留固定协议错误与通道退出类别，无自动重连、重试或错误吞并。

driver将业务首因与清理结果分开；finally对runtime和issuer各尝试一次ROLLBACK，记录固定阶段/错误码/SQLSTATE/通道状态，不因后续清理覆盖首因。候选、RLS/ACL、身份规则、迁移和10项成功标准未变。
