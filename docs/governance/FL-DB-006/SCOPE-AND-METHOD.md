# 只读范围、方法与限制

本轮在隔离治理工作区工作，仅新增docs/governance/FL-DB-006/；固定后端源码视图只读。TypeScript 5.9.3解析源码，不导入或执行后端模块；读取现有工具库不等于全局安装。Python3用于JSON/CSV一致性与新增目录SHA，未启动服务或数据库。

解析范围290个受控非测试TypeScript源文件及Prisma模型结构；不读取.env、秘密值或现有认证材料。只保留字段名、调用符号、模型/枚举/关联及来源行/SHA，不复制业务全文。699处成员名调用不保证receiver类型完全解析，动态别名/spread不在已证实范围；每表最多6条调用样例、12个路由引用，调用总数另记。216个旧路由符号存在，不代表当前路由装饰器和所有业务语义完全复验；131 Admin结果直接继承，38 LIMITED不消失。

初次静态提取脚本遇到无参数调用时退出TypeError；在任务私有脚本增加空节点保护后重新解析成功。未执行业务代码或SQL，首次失败不影响数据库状态，也不能删除该工具修订记录。

已有formal工作区、三项受保护覆盖层、旧制品ZIP、HMAC/Schema材料、恢复归档及云端历史副本均不读取/修改。没有做全机文件/权限/访问时间快照，因此不证明同UID并发进程未改变文件。GOV2-T09与DEV1-T03/T12历史偏差不被本轮局部校验覆盖。

检查器仅读取本目录；隔离执行前后index、refs、受控工作文件mode和bytes摘要在evidence/scope-check.json中对账。该证据只覆盖检查器区间，不追溯缺失的旧index字节。正式目录未访问是本次调用范围证据，不以缺少访问证明全机从未变化。

受控Git范围以治理基点比较：旧文件mode/blob OID不变、新文件均在本目录。后端290文件SHA与提取记录复核，不重跑业务测试。已许可Draft PR触发仓库现有自动CI；不手动触发完整Jest、业务测试、部署或环境流程，自动CI不充当本轮数据库动态证据。

敏感扫描只检查新增治理文件的显式格式、赋值材料与高熵字符串；允许的哈希/对象ID必须具备摘要或Git身份结构语义，不按整目录白名单。没有真实密钥比对，零命中不证明项目没有有效秘密。SHA256SUMS覆盖除自身外全部新增文件；清单自身SHA在仓库外HANDOFF记录，避免自引用。
