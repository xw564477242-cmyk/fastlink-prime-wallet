# 基线豁免与到期机制（PENDING）

申请必须记录原因、精确范围、审批人角色、批准时间、实际变更时间、到期时间、风险、回滚方案、回补工单、是否产生持久影响以及到期状态。缺失审批或期限为INVALID；资金、多租户、秘密、生产安全红线为FORBIDDEN，不能豁免。

持久变更最迟在实际变更与批准两者较早时间起48小时内回补五级门禁；期限不得通过晚补批准时间延长。到期未完成为OVERDUE-GATES，暂停依赖其成果的复用，交总控处理；不自动延长或关闭。

临时且无持久影响的验证到期后，须有“无持久影响”证据与责任人确认，生成EXPIRED-ARCHIVE-PROPOSAL供审批归档；无确认则EXPIRED-REVIEW-REQUIRED。归档仅追加状态记录，绝不删除验证资产或审计证据。

本机模型只评估字段、时间和红线，不执行变更、审批、回滚、销毁或归档。本工单没有批准任何实际豁免。
