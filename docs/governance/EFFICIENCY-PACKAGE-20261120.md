## 2. Gate1 卡点表（替代长文承接）

Gate1 不是靠计分堆出来的，卡点只有下面 5 个。每行只需一个裁定，裁定完全表即可推进。

| # | 卡点 | 影响面 | 需要谁的裁定 | 通过判据 |
| --- | --- | --- | --- | --- |
| 1 | 16 槽真实历史样本来源 | 槽 10/16 → 16/16；调用点 31/47 的余量 | 所有者指定来源，或宣布不可得 | 有绑定样本 + 独立读回，或正式登记"不可得"并关闭该槽 |
| 2 | 6 个历史修复槽的独立审批身份 | S11 及历史修复槽 | 所有者指派合格身份，或确认无人 | 非 superuser / 无 BYPASSRLS / 与 app·issuer·worker 分离，且属既有修复审批角色 |
| 3 | `FASTLINK_LEGACY_CARD_REPAIR_ADMISSION` | 修复准入是否可测 | 授权设置，或不设 | Railway 变量变更经工具级审批；未设置则外层通过后为 404，不能算拒绝证据 |
| 4 | 余 34 项 P0 离线项 | P0 56/90 → 90/90 | 指定最先 5 项 | 每项附离线回执 SHA |
| 5 | H67 / H71 / H65 / H73 四 UNKNOWN | 调用点余量中的 4 点 | 批准合成探针，或长期挂起 | 探针实测回执，或登记挂起 |

**用法**：任何"下一步做什么"的问题，答案只能从这张表里取。表外事项一律视为新增范围，需单独裁定。

## 3. 批准卡模板 v2（一页替代十四个目录）

原则：**一张卡 = 一个动作目标**。范围裁定不进卡。

### 必填七字段

| 字段 | 要求 |
| --- | --- |
| 动作 | 一句话，含目标表/目标行 |
| 预算 | 连接数 / 事务数 / 语句数 / 控制路径数 / 重试次数（默认 0） |
| 绑定 | 封包 manifest SHA + 主文档 SHA，双哈希 |
| 前置 | 执行前必须成立的状态断言（漂移即回滚） |
| 副作用 | 明确列出允许的既有副作用（会话撤销、审计、凭据交接等） |
| 失败路径 | 提交未知 / 已提交 / 未提交 三态各自处理规则 |
| 判据 | 通过的最小可验证证据集，缺一项即降级为部分完成 |

### 现成示例：Admin B 恢复

```
动作：封定单行改密（TEST Admin B）+ 撤销其原未撤销会话
预算：3 连接 / 3 事务 / 17 参数化语句（15 SELECT + 2 DML）/ 成功 6 控制、提交未知后 7 控制 / 0 重试
绑定：REVIEW.md a1318cb8271dd1f0de3d8987859c9011f3b93b5df9e029b7c663c3985cf9b3b2
      清单     c79204e1569415aad2f416cdbcae9618c7e0f86321b27b419df6b4d6939d6858
前置：同集群/OID/身份/日志参数一致；目标单行前态未漂移；用户级 advisory 锁已取
副作用：issuer capability 撤销 / session_proof / identity_audit 等既有副作用允许
失败路径：未提交→清暂存；提交未知或已提交→保留唯一私有凭据并停止，不重试 COMMIT、不回填旧哈希
判据：单行改密 + 原会话撤销 + login/me/logout 各 1 + 私有 0600 凭据发布（五项齐）
```

配套标志位：`acceptVerifiedFunctionBindings=true`、`allowConnectionLocalSafetyOptions=true`、`approveExecution=true`。
（说明：第 1、2 项为技术准入接受，第 3 项才是执行放行。三者分开签，便于将来只批准入不批执行。）

## 4. 复杂度刹车三条（建议追加进 `AGENTS.md`）

1. **任何新工单必须在标题里写明它移动哪个门禁或哪个计数分子**；写不出来就不立。
2. **同一结论不得第二次立项**——已验项只引用 SHA，不重新核对、不重新整理、不重新对齐。
3. **单次执行批准只含一个动作目标**；样本来源、权限变更、范围调整一律另立裁定，不夹带进执行批准。

预期效果：当日文档量从 3,710 行降到千行以内；"承接/纠正/边界同步"类文档归零。

## 6. 改造后的工作循环（目标形态）

1. 开工：读《状态指针》一页 → 从卡点表取一项。
2. 执行：按批准卡 v2 七字段装配，一个动作一个目标。
3. 回执：只写通过/失败/部分完成三态 + 判据证据 SHA。
4. 回写：更新状态指针的计数行 + 卡点表该行。**不新增承接文档。**

预期：单轮闭环文档量下降一个数量级，同时证据标准不降。
