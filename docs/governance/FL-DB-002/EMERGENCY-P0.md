# DB2-R01 脱敏紧急报告

- 等级：**P0 / 确认应用层跨租户读取缺陷**
- 确认范围：本机隔离环境、固定后端源码、原始Nest路由/守卫/服务、合成双租户、内存持久层边界
- 部署范围：DEV/TEST/UAT/生产均未验证
- 秘密/真实数据：未使用、未读取、未输出
- 首次确认后：立即停止扩展动态测试，服务停止，后续请求0

非秘密事实：普通租户管理员直接读取其他租户详情会被拒绝；当同一请求加入声明自己租户的冲突query参数时，守卫校验query租户，而控制器按路径租户读取，返回了其他租户的合成详情。

潜在影响：Admin租户详情；同一守卫覆盖的其他入口在路径对象与query/body租户可冲突时应标记 `STALE`，但尚未逐项证明。当前不能宣称生产可达、已发生泄露或所有Admin入口均受影响。

立即控制建议：继续关闭资金功能；在独立P0整改工单修复“授权对象必须与实际资源对象一致”，增加冲突参数拒绝及全量Admin入口定向回归；整改合并前不要开展外部环境利用性扩展。是否需要部署侧临时限制、日志审计或令牌处置由项目所有者/安全负责人在获授权环境中决定，本工单不执行。

禁止事项：不输出令牌、不认证既有凭据、不连接已部署环境、不修改业务代码/权限/数据库、不执行GC/历史重写、不删除证据。
