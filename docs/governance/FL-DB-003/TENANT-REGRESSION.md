# 双租户与Admin回归

新增10项HTTP集成回归，使用合成租户、合成资源和内存服务：

- 同租户读取及写入成功；
- GET、POST、PATCH、DELETE的path/query冲突均返回403；
- path/body冲突返回403；
- 普通租户管理员会话与资源租户冲突返回403；
- 路径租户正确但资源实际属于其他租户时返回统一404，不泄露外租户标识或资源存在性；
- 缺失租户上下文的普通管理员请求返回403；
- 保留现有显式platform读取权限；平台请求携带冲突tenant参数仍返回403。

共享守卫单元与租户控制器单元合计16项通过。完整既有测试为1,761项通过、2项既有跳过、0失败。首次在受限沙箱内运行完整测试时，仅因本机HTTP监听权限导致25项失败；以相同代码在获准的本机隔离监听条件下复跑后全部相关失败消失，该事件不是业务回归。

未连接数据库、资金服务、Thredd或Cregis。未测试已部署平台管理员身份、实际角色或GRANT。
